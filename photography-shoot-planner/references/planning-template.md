在正式策划中，只展开本次需要的条目。样片/镜头方案中只放用户实际提供的图片，并直接嵌入图片或使用其真实链接，不用“样片一、样片二”等文字代替。没有提供的景别统一放入独立的“景别缺口与补拍建议”模块，标注“补拍建议｜待配参考图”；不要把新增构想伪装成已有样片。每条真实参考镜头或补拍建议必须提供机位、光位与描述，且说明本条镜头要完成的画面任务。

交付为 `index.html` 时，按上述章节生成完整 HTML 页面。样片部分按景别分节，每条真实参考镜头展示原图及“机位、光位、描述”字段；同一景别使用响应式 CSS Grid，宽屏每行三列，窄屏两列或一列。图片以相对路径引用同目录下 `assets/` 中的原图，并可点击查看完整图片；保持画幅比例，不裁切。没有真实参考图的景别只写入“景别缺口与补拍建议”，不生成空白样片卡片。
