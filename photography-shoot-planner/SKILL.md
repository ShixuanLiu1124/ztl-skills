# 摄影策划

根据用户给出的样片，先判断画面风格与景别覆盖，再写可执行的摄影策划初稿。策划要延续样片可观察到的审美方向，同时补足拍摄叙事所需的镜头。不要默认生成固定数量的镜头，也不要声称读到了未提供的参考。

## 工作方式

1. 用户给出样片时，先逐张查看并进行景别盘点，再产出策划初稿。用户只要求样片分析时，只交付盘点和补拍建议；用户只给主题时，直接写初稿并标明必要假设。
2. 从样片与对话中提取主题、情绪、人物、场地线索、色彩、光线、服装、动作和叙事。区分画面中直接可见的信息与复现建议；无法确认的焦段、布光设备或拍摄参数不可写成事实。
3. 缺少会改变方案的核心信息时，集中询问至多三个问题，优先拍摄主题、地点和可拍时间。未确定的日期、场地、预约、预算或人员标为“待确认”。
4. 完整摄影策划按“交付与保存”规则交付；只做样片盘点、补拍建议或简短答疑时，直接在聊天中回答。用户要求其他文档格式时再创建相应文件；不擅自修改用户已有的飞书文档。

## 交付与保存

完整摄影策划优先交付为个人云盘（飞书云空间）「摄影策划」文件夹中的飞书云文档；无法创建飞书云文档时，依次回退到本地 Markdown 文件或聊天交付。

1. **定位目标文件夹**。先读取 `lark-drive` 技能（`lark-drive/SKILL.md`），用 `drive +search --query "摄影策划" --doc-types folder` 在个人云盘定位「摄影策划」文件夹；不存在时用 `drive +create-folder` 在云空间根目录创建同名文件夹，并记录其 folder token。
2. **优先：飞书云文档**。完成完整策划后，读取 `lark-doc` 技能（`lark-doc/SKILL.md`）并按其创建流程新建飞书云文档，将完整策划写入文档；创建时通过 `docs +create --parent-token <摄影策划文件夹 token>` 把文档直接创建在「摄影策划」文件夹内。正文排版按下文“飞书云文档排版”一节执行。文档标题使用 `摄影策划-主题-YYYYMMDD-HHmm`，主题未知时使用 `未命名主题`。创建成功后，聊天回复简要说明已完成，并通过 present_files 交付文档链接。
3. **回退：本地 Markdown 文件**。飞书云文档创建失败（如无权限、环境不可用），或用户明确要求本地文件时，在 Windows 上将完整内容保存为 UTF-8 编码的 Markdown 文件到 `E:\摄影策划`。目录不存在时创建目录。文件名使用 `摄影策划-主题-YYYYMMDD-HHmm.md`；清理 Windows 文件名不允许的字符，主题未知时使用 `未命名主题`，同名时追加递增序号而不是覆盖已有文件。若云盘可写，可同时用 `drive +upload` 把该文件上传到「摄影策划」文件夹。聊天回复中简要说明已完成并给出路径或链接。
4. **兜底：聊天交付**。飞书云文档与本地文件均不可用时，直接在聊天中交付完整策划，并明确说明未保存文件及原因。

用户明确指定其他保存位置或格式时，以用户当次要求为准。

## 飞书云文档排版

创建飞书云文档时，正文排版参考示例文档《粉黛子摄影策划》（https://my.feishu.cn/docx/YQmsdJVc1oL1dMxsriRcUbydnGd）：

- 章节顺序沿用“策划初稿结构”：地点、时间、妆造（服装建议／妆容建议／发型建议）、道具、样片；样片部分按景别分节（如近景&特写、中景、全景、远景、空镜），只保留本次实际需要的景别。
- 每节样片先写“机位、光位、描述”字段（必要时加“引导”），再把该景别的样片图片以分栏排布：每行三列等宽分栏（grid，各列 width-ratio 约为 0.333333），每个分栏内放一张样片图片。
- 样片图片取自用户提供的样片，按 lark-doc 技能指引插入；图片不足或需占位时，分栏内以文字填充（如“【样片】、机位：、光位：、描述：”），保持分栏结构。

## 样片盘点：远、全、中、近、特

对每张有人像的样片指定一个主景别；构图跨界时可补充次景别，但统计只计主景别，避免重复计数。空镜单列，不混入五类景别。

| 景别 | 判定重点 |
| --- | --- |
| 远景 | 人物在环境中占比很小，地点、空间或氛围主导画面。 |
| 全景 | 以完整人物和整体姿态为主，服装与环境关系清楚。 |
| 中景 | 多为膝盖/腰部至头部，重点是身体语言和人与道具的关系。 |
| 近景 | 多为胸口/肩部以上，重点是表情、肩颈和局部姿态。 |
| 特写 | 聚焦脸部、眼睛、手、饰品、服装纹理或其他细节。 |

盘点时：

- 先列出“样片编号｜主景别｜画面作用｜可借鉴要点”，再给一张汇总表：景别、数量、已覆盖的画面作用、缺口。
- 把数量为 0 的景别明确标为“极度缺少”；若所有类别都有样片，则结合数量、场景变化和叙事作用，按缺口从大到小列出“最缺、次缺”。没有足够样片时，说明样本不足，不能假装统计精确。
- 不以均分或固定张数作为好坏标准。判断缺口时看这组样片能否交代环境、人物全貌、互动动作、情绪和细节；例如只有近景和特写时，远景与全景通常是优先补拍对象。
- 对每个缺口给出 1–3 个具体补拍方向，写清目标景别、画面任务、人物或环境安排。不要把“更多镜头”本身当成建议。

## 策划初稿结构

阅读 [references/planning-template.md](references/planning-template.md)，沿用其章节顺序和每条样片的“机位、光位、描述”字段。初稿依次包含：

1. **样片盘点与补拍优先级**：先给远、全、中、近、特的覆盖结论，再说明本次策划会怎样补足缺口。
2. **地点、时间、妆造、道具**：围绕样片中可见的主题和实际拍摄条件安排。地点写可用场景元素；时间写光线和流程；妆造写服装、妆容、发型；道具说明画面用途和使用动作。
3. **样片/镜头方案**：按本次需要选择远景、全景、中景、近景、特写和空镜，不要求每类都有相同数量。实际参考图用其编号或链接；新增的构想标为“待配参考图”。每条保留“【样片】、机位：、光位：、描述：”。

镜头数量由拍摄时长、换装、转场、用户指定数量和叙事需求决定。用“必拍”和“备选”说明优先级，避免为凑数量堆叠相似构图。

## 写到可执行的程度

**机位**写相机相对人物的位置、高度、俯仰、横竖构图和取景范围；**光位**以人物面朝方向说明光从哪一侧、何种方向和质感而来，并说明转身或换站位的方法；**描述**写动作、手部、视线、表情、画面重点与情绪。不同景别承担不同任务：远景交代环境，全景呈现人物与服装，中景呈现动作和关系，近景传达表情，特写保留情绪或材质细节，空镜连接场景。

自然光方案不能假定太阳方向可任意改变。器材未知时，优先用站位、构图和光线方向说明方法，而不把某支镜头或灯具当作前提。

## 交付前检查

确认每张已给样片都被盘点或说明无法判断；远、全、中、近、特与空镜未混淆；“极度缺少”有明确的数量或画面作用依据；补拍建议可执行；策划的地点、光线、妆造和动作属于同一主题；每条镜头均有实质性的机位、光位和描述；实际样片、推测、待配参考图和待确认事项区分清楚；以飞书云文档交付时，样片已按景别分节并以三列等宽分栏排布，且文档已创建在个人云盘「摄影策划」文件夹内。
