# 摄影策划

将拍摄主题和现场条件写成摄影师、模特与妆造人员可以直接执行的策划。以用户在对话中粘贴的结构为依据；原飞书链接未读取，不声称已复刻其排版或图片。本技能是写作工作流，不是模板库中的文档模板。

## 使用方式

1. 阅读 [references/planning-template.md](references/planning-template.md)，沿用标题、顺序和每张样片的三个字段。修改已有策划时，优先沿用该稿已经确定的内容，只调整用户要求的范围。
2. 从当前对话、用户素材和已有策划提取主题/情绪、人物、城市/场地、日期/时段、时长、可用服装道具、器材与团队条件。不要重复询问已提供的信息。
3. 如果缺失信息会改变整个方案，集中询问至多三个关键问题，优先主题、场地和拍摄时间。能够先写的部分继续完成。用户只给主题或要求直接出稿时，以简短的“策划假设”说明必要假设；未确定的具体地点、日期、预约、预算或人员标注“待确认”，不要写成已落实。
4. 默认用中文在聊天中交付可复制的完整策划。用户要求文件时再选用相应文档工具；需要 Word/PDF 等格式时遵循可用的文档技能。不擅自创建或修改飞书文档。

## 固定结构与数量

- 地点 → 时间 → 妆造（服装建议、妆容建议、发型建议）→ 道具 → 样片。
- 完整版保留 42 个镜头：近景&特写 12、中景 12、全景 9、远景 6、空镜 3。按组编号，便于引用和修改。
- 用户指定数量、精简版或仅某一章节时按要求调整，不强制补齐 42 个。不要把 42 个方案写成一次短拍摄全部必须完成的任务；在各条“描述”内标注必要的必拍/备选，优先保住风格与可执行性。
- 每条保留“【样片】、机位：、光位：、描述：”，不能以一段泛泛的风格介绍代替分镜。

## 写到可执行的程度

**地点**：写具体可用的场景元素、背景与人物站位、可选区域。没有确定城市或场地时给场景类型与筛选条件，避免编造店名、营业时间或拍摄许可。

**时间**：写建议时段及其对光线的作用，给妆造、拍摄、换装和转场留出合理时间。未查证具体日期/地点时使用“日落前约一小时”等相对建议；不要把固定钟点当成精确黄金时刻。要提供天气、日落时间、场地开放或预约信息时先查证并附来源，无法查证则标注待核实。

**妆造**：围绕同一个主题写服装颜色、轮廓、面料、鞋袜与配饰；妆容落到肤感、眉眼、唇色；发型落到轮廓、分缝、扎法和固定方式。结合用户已有物品与偏好，不凭空要求多套服装、专业团队或额外购买。

**道具**：说明每件道具的画面用途、使用动作及是否可选；优先复用现有物品。没有必要时可写“无需额外道具”。

**机位**：说明相机相对人物的位置、机位高度、俯仰角度、横竖构图与取景范围；在有帮助时补充大致距离或焦段建议。器材未知时以相对位置和画面范围为主，不把具体镜头当成执行前提。

**光位**：以人物面朝方向为基准说明光从左/右、前/侧/后哪个方向来，光源类型、软硬、人物如何转身，以及需要时的补光方式。区分机位方向与光源方向。采用自然光时不能假定太阳位置可随意改变；需要大幅改变光向的镜头应通过换站位、转身或换时段实现。

**描述**：写人物动作、手部安排、视线、表情、画面重点与希望传达的情绪。用可操作的动作表达情绪，例如“手指轻捏衣角、视线落向窗外”，避免仅写“高级、氛围、松弛”。可在此字段内补充拍摄顺序、必拍/备选或注意事项，不另起一套复杂表头。

各景别的用途不同：近景&特写抓脸、手和质感；中景讲身体动作与道具关系；全景看完整人物、服装与姿态；远景强调人物与环境的比例；空镜拍无人环境、光影和静物来连接故事。同组镜头通过动作、构图或叙事重点形成差异，避免只替换形容词来凑数。

## 样片与参考图片

- 用户给出图片时先查看实际画面，再写对应分析。明确区分画面可观察信息与推测；无法从图片确认的光源、焦段或布光距离只能写为推测/复现建议。
- 已有可访问的参考图可以在“【样片】”下嵌入图片或附可用链接，并说明借鉴点；不要把样片原作中的器材、模特身份等未知信息写成事实。
- 没有实际图片时写“【样片】编号｜镜头名（待配参考图）”，随后给出拍摄构想及三个字段。可附简短找图关键词，但不能声称已找到、已看过或已附上照片。
- 用户要求搜索样片时，使用可用的图片/网页搜索，检查相关性并保留可访问的来源；检索失败时明确说明，保留待配图状态。不要捏造图片地址、来源或摄影师署名。
- 用户明确要求生成参考图时使用可用的图像生成工具，将结果标为“AI 生成示意图”。不要默认批量生成 42 张图片，也不要把示意图说成实拍样片。

## 交付前检查

检查章节和镜头数量符合本次要求；每条机位、光位、描述均有实质内容；妆造、地点、光线和动作属于同一个主题；拍摄时长与必拍数量、换装和转场相容；光线、站位和器材建议没有互相矛盾。检查实际参考图、推测、构想和待确认信息是否清楚区分。将真正影响执行的未决事项集中在文末简短列出，不附通用冗长说明。
