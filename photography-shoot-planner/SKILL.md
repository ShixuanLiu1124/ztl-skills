# 摄影策划

根据用户给出的样片，先判断画面风格与景别覆盖，再写可执行的摄影策划初稿。策划要延续样片可观察到的审美方向，同时补足拍摄叙事所需的镜头。不要默认生成固定数量的镜头，也不要声称读到了未提供的参考。

## 工作方式

1. 用户给出样片时，先逐张查看并进行景别盘点，再产出策划初稿。用户只要求样片分析时，只交付盘点和补拍建议；用户只给主题时，直接写初稿并标明必要假设。
2. 从样片与对话中提取主题、情绪、人物、场地线索、色彩、光线、服装、动作和叙事。区分画面中直接可见的信息与复现建议；无法确认的焦段、布光设备或拍摄参数不可写成事实。
3. 缺少会改变方案的核心信息时，集中询问至多三个问题，优先拍摄主题、地点和可拍时间。未确定的日期、场地、预约、预算或人员标为“待确认”。
4. 完整摄影策划按“交付与保存”规则生成 HTML；只做样片盘点、补拍建议或简短答疑时，直接在聊天中回答。用户明确要求其他格式或保存位置时，以当次要求为准。

## 交付与保存

完整摄影策划默认交付为本地 UTF-8 HTML 文件，不创建或写入飞书云文档。

1. **保存目录**。macOS 默认保存到 `/Users/liushixuan.6/Documents/摄影策划`；Windows 默认保存到 `E:\摄影策划`；其他系统选择用户可写的本地目录。每期创建 `YYYY-MM-DD-主题` 子目录，主题未知时用 `未命名主题`。清理路径不允许的字符；同名目录追加 `-02`、`-03`，不覆盖已有策划。
2. **生成文件**。子目录内保存 `index.html` 和 `assets/` 参考图目录。HTML 使用 UTF-8、完整的文档结构和内嵌 CSS，不依赖在线样式或脚本。将可访问的用户样片复制到 `assets/`，在 HTML 中以相对路径引用；保留原图，不为排版裁切。若图片只有无法下载的原始链接，在页面中保留真实链接并说明查看时需要访问该链接，不把文字占位伪装成图片。
3. **交付**。生成后检查 HTML 可打开、正文完整、图片路径有效，并在聊天中给出 `index.html` 的实际绝对路径及简要说明。若本地文件无法保存，直接在聊天中交付完整策划，说明未保存的原因。

## HTML 排版

- 章节顺序沿用“策划初稿结构”；样片/镜头方案按本次实际需要的景别分节，只展示用户真实提供的参考图。
- 每条真实参考镜头在图片旁写“机位、光位、描述”（必要时加“引导”和“画面任务”）。同一景别的镜头用响应式 CSS Grid 排布：宽屏每行三列，窄屏自动变为两列或一列；不为了凑满一行添加空白样片。
- 每张图片完整展示，保持原始画幅比例；图片可点击打开原图。对用户输入的文本和图片路径做 HTML 转义，避免破坏页面结构。

**参考图边界：** 只有用户实际提供的图片才能作为样片或参考图写入样片盘点和镜头方案。对于没有提供图片的景别，不得凭空构造、生成或暗示存在一张样片；该条只能标为“待配参考图”或放入独立的补拍建议模块。参考图编号、缩略图和图片链接必须一一对应真实提供的图片。

**样片展示：** 真实样片必须完整展示，保留原始画幅比例，不使用固定高度配合 `object-fit: cover` 等会裁切主体的样式。可以设置最大宽度或最大高度，但缩放必须是等比例的；如果需要缩略图，也要同时提供可查看完整原图的方式。

## 样片盘点：远、全、中、近、特

对每张有人像的样片指定一个主景别；构图跨界时可补充次景别，但统计只计主景别，避免重复计数。空镜单列，不混入五类景别。

| 景别 | 判定重点 |
| --- | --- |
| 远景 | 人物在环境中占比很小，地点、空间或氛围主导画面。 |
| 全景 | 以完整人物和整体姿态为主，服装与环境关系清楚。 |
| 中景 | 多为膝盖/腰部至头部，重点是身体语言和人与道具的关系。 |
| 近景 | 多为胸口/肩部以上，重点是表情、肩颈和局部姿态。 |
| 特写 | 聚焦脸部、眼睛、手、饰品、服装纹理或其他细节。 |

盘点时：

- 先列出“样片编号｜主景别｜画面作用｜可借鉴要点”，再给一张汇总表：景别、数量、已覆盖的画面作用、缺口。
- 把数量为 0 的景别明确标为“极度缺少”；若所有类别都有样片，则结合数量、场景变化和叙事作用，按缺口从大到小列出“最缺、次缺”。没有足够样片时，说明样本不足，不能假装统计精确。
- 不以均分或固定张数作为好坏标准。判断缺口时看这组样片能否交代环境、人物全貌、互动动作、情绪和细节；例如只有近景和特写时，远景与全景通常是优先补拍对象。
- 对每个缺口给出 1–3 个具体补拍方向，写清目标景别、画面任务、人物或环境安排。不要把“更多镜头”本身当成建议。

### 景别缺口与补拍建议

将缺少的景别单独放在“景别缺口与补拍建议”模块，不要混入“样片/镜头方案”中伪装成已有参考。每条建议可以写目标景别、画面任务、人物或环境安排、建议机位和光位，但必须明确标注“补拍建议｜待配参考图”。如果用户要求只分析样片，则只输出这个模块，不扩写成完整拍摄镜头。

## 策划初稿结构

阅读 [references/planning-template.md](references/planning-template.md)，沿用其章节顺序和每条样片的“机位、光位、描述”字段。初稿依次包含：

1. **样片盘点与补拍优先级**：先给远、全、中、近、特的覆盖结论；缺少的景别另设“景别缺口与补拍建议”模块，明确区分已提供样片和新增构想。
2. **地点、时间、妆造、道具**：围绕样片中可见的主题和实际拍摄条件安排。地点写可用场景元素；时间写光线和流程；妆造写服装、妆容、发型；道具说明画面用途和使用动作。
3. **样片/镜头方案**：只展开有真实参考图支撑的镜头；实际参考图用对应图片或链接，不得用文字编号替代图片。没有参考图的景别移至“景别缺口与补拍建议”，不要在这里制造“待配参考图”的伪样片卡片。每条保留“参考图、机位、光位、描述”字段。

镜头数量由拍摄时长、换装、转场、用户指定数量和叙事需求决定。用“必拍”和“备选”说明优先级，避免为凑数量堆叠相似构图。

## 写到可执行的程度

**机位**写相机相对人物的位置、高度、俯仰、横竖构图和取景范围；**光位**以人物面朝方向说明光从哪一侧、何种方向和质感而来，并说明转身或换站位的方法；**描述**写动作、手部、视线、表情、画面重点与情绪。不同景别承担不同任务：远景交代环境，全景呈现人物与服装，中景呈现动作和关系，近景传达表情，特写保留情绪或材质细节，空镜连接场景。

自然光方案不能假定太阳方向可任意改变。器材未知时，优先用站位、构图和光线方向说明方法，而不把某支镜头或灯具当作前提。

## 交付前检查

确认每张已给样片都被盘点或说明无法判断；没有提供的样片没有被凭空构造；远、全、中、近、特与空镜未混淆；缺少景别已在独立的“景别缺口与补拍建议”模块中说明；“极度缺少”有明确的数量或画面作用依据；补拍建议可执行；策划的地点、光线、妆造和动作属于同一主题；每条真实参考镜头均有实质性的机位、光位和描述；实际样片、推测、补拍建议和待确认事项区分清楚。交付 HTML 时，确认页面可打开、样片按景别分节且完整显示、图片引用有效，并已返回实际文件路径。
